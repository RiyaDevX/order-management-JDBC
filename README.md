# Project 1: Order Management System (Java JDBC + MySQL)

## How to Implement & Run
1. Run `setup.sql` in MySQL to create `ecommerce_db` and the `Orders` table.
2. Open the extracted `Q1_Order_Management_JDBC` folder in **IntelliJ IDEA Ultimate** (`File > Open`).
3. Replace `YOUR_MYSQL_PASSWORD` in `OrderManagementSystem.java` with your MySQL root password.
4. Run `OrderManagementSystem.main()` and test options 1–5.
